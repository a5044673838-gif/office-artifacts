An entry for make.fun's "Office Artifacts: The One-Line Placard Contest"
bounty ($2 in USDC). One line, a museum placard for an ordinary office
stapler, presented as an ancient artifact dug from a lost civilisation.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
